Virtual Network Workstation

Interactive, stateful browser simulation. Diagnose a fictional workstation with the wrong DNS resolver and gateway; correct the approved settings and verify. Commands affect only this fictional model, never your real device or a network.

Mission: Restore portal connectivity

The lab host is configured with DNS 192.0.2.53 and gateway 192.0.2.254. The approved configuration is DNS 192.0.2.54 and gateway 192.0.2.1. Investigate before applying changes. Type help for supported commands.

Network terminal

student@netlab:~$

Skills assessed

Inspect the current IP, route, DNS, and baseline failed lookup; compare to the approved configuration; make both corrections; prove a successful hostname HTTPS test. The objective score is 10 points: four for distinct evidence, four for both correct settings, two for a successful verification.
