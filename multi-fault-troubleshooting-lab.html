Multi-Fault Troubleshooting Lab

Four simulated cases each contain two interacting failures. The cause is hidden until grading. Commands only change fictional local state. No real operating-system commands, network requests, or configuration changes occur.

Mission: Restore the training portal

Investigate, correct both root causes, and verify the service end to end. Aim to use only the necessary changes. Type help for supported commands.

Simulated terminal

student@multilab:~$

Objective scoring

Four points for observing at least three distinct diagnostic categories; two points for restoring both faulty components; two points for proving HTTP success; two points for changing exactly the faulty components and no others. Best scores for all cases are saved separately from existing coursework.
