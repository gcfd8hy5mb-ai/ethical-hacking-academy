Virtual Windows Workstation

This is a safe, stateful PowerShell simulation. You are troubleshooting a fictional Windows inventory service. The browser does not execute commands on a Windows computer.

Mission: Restore InventoryApp

After approved maintenance, InventoryApp has stopped because its configuration path is wrong. Investigate the service and event record, correct the simulated path, and verify that a normal inventory transaction works.

Use help to list supported mock commands. The lab models a simplified service and does not provide arbitrary PowerShell execution.

Assessment objectives

Demonstrate identity and service inspection, interpret the relevant Windows event, compare the maintenance change record, correct the service configuration, and verify both service status and application functionality. Avoid disabling protections or deleting evidence.
