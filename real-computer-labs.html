2 · Windows observational triage

Get-Process | Sort-Object CPU -Descending | Select-Object -First 5 Name,Id,CPU
Get-Service | Select-Object -First 10 Name,Status,StartType
Get-NetIPConfiguration | Select-Object InterfaceAlias,IPv4Address,IPv4DefaultGateway

Interpret: process CPU is cumulative seconds; a stopped service can be normal. Capture the local status and give one benign alternative to a suspicious-looking condition.

3 · Linux system interpretation

whoami
pwd
ps -eo pid,comm,%cpu --sort=-%cpu | head -n 6
ip route show

Interpret: identify your current user, top processes and default route if one exists. Missing commands or empty route data are observations, not reasons to change the machine.

4 · Python defensive log analysis

from pathlib import Path
from collections import Counter
import csv
with (Path.home() / "academy-batch3-lab" / "events.csv").open(newline="", encoding="utf-8") as stream:
    events = list(csv.DictReader(stream))
print(Counter(row["result"] for row in events))

Expected: two successes and two failures. Explain why a count alone does not prove an incident.
