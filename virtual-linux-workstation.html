Virtual Linux Workstation

A stateful, browser-only filesystem lab. Unlike a fixed-output quiz, commands read a simulated directory tree, and approved changes persist within the lab until reset. It never executes operating-system commands or connects to other computers.

Mission: Restore the reports service

The reporter account cannot write its output. Investigate using the shell, adjust only the simulated lab directory, and demonstrate that the service can write without making it world-writable.

  1. Identify your account and current location.
  2. Inspect the output directory and reporter identity.
  3. Correct the output directory group and permission bits.
  4. Run check-service and grade-lab.

Try help. The system accepts supported commands and arguments, not arbitrary shell programs.

Simulated terminal

academy@virtual:~$

Learning objectives

Identity: whoami, pwd, id reporter.

Inspection: ls -ld /srv/reports/out, stat /srv/reports/out, cat /var/log/reporter.log.

Controlled correction: chgrp reports /srv/reports/out, chmod 770 /srv/reports/out.

Verification: check-service, grade-lab.

All writes affect fictional lab state only. No privilege escalation, network operations or arbitrary shell evaluation.
